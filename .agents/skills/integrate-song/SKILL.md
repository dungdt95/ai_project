# Song Integrator & Karaoke Aligner Skill (v2 – High-Precision DSP + Multimodal)
# Song Integrator & Karaoke Aligner Skill (v2.2 – DSP Bar-Grid + Clip-Slice Verification)

This skill integrates an MP3 song file into any topic (`t01` through `t25`) of the "Bé Vui Tiếng Anh" Flutter app (`kids_english_app/app`), combines **DSP Vocal Formant Isolation & Onset Detection** (`integrate_song.js`) with native multimodal audio listening (`read_file` on at most **1–2 MP3 files per turn**), and calibrates `0.1s`-precision timestamps for every lyric line.
This skill integrates an MP3 song file into any topic (`t01` through `t25`) of the "Bé Vui Tiếng Anh" Flutter app (`kids_english_app/app`), uses **DSP Vocal Formant Isolation & Bar-Grid Dynamic Programming** (`integrate_song.js`) combined with **short sliced clip verification** (`--slice`), and applies verified `0.1s`-precision timestamps (`--apply`).

## Step-by-Step Procedure

1. **Run DSP Vocal Envelope & Onset Analysis (`integrate_song.js`)**:
   - To copy a new MP3 and analyze it:
     ```powershell
     node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js "<topic>" "<mp3_file_path>"
     ```
   - Or to analyze already-copied song(s) in `assets/audio/songs/`:
     ```powershell
     node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js --analyze t06 t07
     ```
   - The script filters strictly to the human singing formant band (`320Hz–3400Hz`), removes stereo side instruments (`Mid - 0.78 * Side`), and outputs:
     - **First Vocal Entry (`~X.Xs`)** and **Last Vocal Exit (`~Y.Ys`)**
     - **Estimated Tempo & Bar Duration (`1 bar ≈ 2.2s–2.5s`)**
     - **Detected Phrase Onsets** (physical timestamps where singing starts after an instrumental intro or breath pause)
     - **0.2s Stereo Center-Vocal Envelope** with `<-- ONSET` and `(pause/inst)` markers.
1. **Run DSP Vocal Envelope & Bar-Grid Proposal (`integrate_song.js`)**:
   ```powershell
   node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js --analyze t06
   ```
   The script isolates the center vocal band (`320Hz–3400Hz`, `Mid - 0.85 * Side`), detects `First Vocal Entry`, `Last Vocal Exit`, `Estimated Tempo`, and prints `Suggested 8-Line Timestamps (Bar-Grid DSP)`.

2. **Listen Directly to the MP3 with `read_file` (CRITICAL RULE: MAX 1–2 MP3s PER TURN)**:
   - **NEVER call `read_file` on more than 2 MP3 files in the same turn!** Loading 5–9 audio files in one turn degrades multimodal temporal attention and causes large timestamp drift.
   - Call `read_file` on 1 or 2 MP3 files at a time while looking at their DSP Vocal Envelope from Step 1:
     - Match the **First Vocal Entry** from the DSP chart to Line 1's actual start time `t` (e.g., if the intro ends and singing begins at `9.6s`, Line 1 MUST start at `9.6`, NEVER at `2.1`!).
     - Match each subsequent line (`Line 2..8`) to the exact `ONSET` / bar grid in the DSP chart.
     - Pay special attention to:
       - **Held notes or 2-bar lines** (e.g., a line held for 2 bars = `~4.8s`, or an instrumental interlude between verse 1 and verse 2 where `V` drops to `< 0.15` for several seconds).
       - **Repeated lines or extra sung phrases**: if the singer repeats a chorus or line in the MP3, include or adjust the lyric lines in `song.lyrics` so the text on screen always matches what the singer is singing at that timestamp.
2. **Slice Short Verification Clips (`--slice`) & Listen via `read_file`**:
   ```powershell
   node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js --slice t06
   ```
   - This creates 8 short 2–3s MP3 clips (`L1_<t1>s.mp3` .. `L8_<t8>s.mp3`) in `scratch/clips_verify/<topic_id>/`.
   - Call `read_file` on the sliced clips (e.g. `L1`, `L3`, `L5`, `L7`, `L8` — short 2.5s clips, NOT full 60s songs!).
   - Because each clip's filename states its exact start timestamp, you immediately hear if a line starts on beat or is early/late by `X.Xs` — adjust accordingly and re-slice if needed.

3. **Update Topic JSON & Re-pack `.bvpack` (if topic is `t06`..`t25`)**:
   - Edit `c:\workspace\ai_project\kids_english_app\app\assets\content\topics\<topic>.json` (`song.lyrics`) with the calibrated `t` values and verified lyric text.
   - If the topic is an expansion pack (`t06`..`t25`), run `dart run tools/pack_topic.dart <topic_id>` (with `BypassSandbox: true`) and sync the updated `.bvpack` and `index.json` to `kids_english_app/docs/packs/`.
3. **Apply Verified Timestamps (`--apply`)**:
   ```powershell
   node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js --apply t06 5.2,7.6,10.0,12.4,14.8,17.2,19.6,23.4
   ```

4. **Re-pack `.bvpack` (for `t06`..`t25`)**:
   Run `dart run tools/pack_topic.dart <topic_id> --version <N>` (with `BypassSandbox: true`) and sync `build/packs/*` to `docs/packs/`.
