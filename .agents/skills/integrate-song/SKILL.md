# Song Integrator & Karaoke Aligner Skill

This skill integrates an MP3 song file into a topic of the "Bé Vui Tiếng Anh" Flutter app (`kids_english_app/app`), uses native multimodal audio perception (`read_file` on the MP3) combined with acoustic waveform timing to extract exact `0.1s`-precision timestamps for every lyric line, and updates the topic's JSON configuration.

## Step-by-Step Procedure

1. **Copy MP3 & Inspect Acoustic Envelope**:
   Run [integrate_song.js](./scripts/integrate_song.js) (use `BypassSandbox: true` if the source MP3 is outside the workspace, e.g., in `C:\Users\User\Downloads`):
   ```powershell
   node c:\workspace\ai_project\.agents\skills\integrate-song\scripts\integrate_song.js "<topic>" "<mp3_file_path>"
   ```
   This copies the MP3 to `kids_english_app/app/assets/audio/songs/<target>.mp3` and prints the exact duration, 0.25s vocal energy envelope, and current JSON lyrics.

2. **Listen Directly to the MP3 with `read_file`**:
   Call `read_file` on the copied workspace asset `c:\workspace\ai_project\kids_english_app\app\assets\audio\songs\<target>.mp3`.
   Listen directly to the singing:
   - Identify the exact start timestamp `t` (with `0.1s` decimal precision, e.g., `2.2`, `4.5`, `6.8`) for each lyric line.
   - Note whether each line occupies 1 bar (~2.28s at 105 BPM) or 2 bars (~4.57s at 105 BPM).
   - Verify whether the sung words match `song.lyrics[i].text` in the topic JSON; if any word differs, update `text` to match the audio.

3. **Update Topic JSON**:
   Edit `c:\workspace\ai_project\kids_english_app\app\assets\content\topics\<topic>.json` (`song.lyrics`) with the calibrated `t` values and verified lyric text.

4. **Validate & Deploy**:
   - Run `flutter test` in `c:\workspace\ai_project\kids_english_app\app` to verify all unit tests pass.
   - If `emulator-5554` is active, rebuild and install `app-debug.apk` so the user can test immediately.
